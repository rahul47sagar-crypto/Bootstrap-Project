# 🧪 ÉLIXIR — Luxury Perfume Login Interface

A high-end, responsive luxury login page designed for **ÉLIXIR Parfums**. Built using HTML5, CSS3, modern Bootstrap 5.3, and vanilla JavaScript. Features a custom CSS-rendered perfume bottle, ambient background glow animations, interactive password toggle, and sleek dark-mode UI.

---

## ✨ Features

- 💎 **Luxury Dark & Gold UI**: Premium aesthetic tailored for high-end luxury brands.
- 🧴 **Pure CSS Perfume Bottle**: Fully customized 3D-styled perfume bottle using raw CSS gradients and shadows.
- 📱 **Fully Responsive**: Seamless layout switching across mobile, tablet, and desktop screens.
- 👁️ **Interactive Password Toggle**: Built-in visual password reveal/hide mechanism.
- ⚡ **Dynamic Form Feedback**: Real-time validation states (`is-invalid`) and clean inline alert notifications instead of default browser alerts.
- 🌐 **Social Authentication UI**: Styled Google login integrated with native Google brand SVG icon.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Variables, Flexbox, Keyframe Animations, Glassmorphism
- **Bootstrap 5.3**: Grid layout & responsive utilities
- **Bootstrap Icons**: Lightweight SVG icons
- **JavaScript (ES6+)**: DOM manipulation & Client-side validation
